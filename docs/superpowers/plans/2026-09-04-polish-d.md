# Полировка D: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Иконка копирования почты морфится в галочку без текста; тихие звуки на ховер интерактивных элементов и на открытие/закрытие меню языка; первая строка описания получает рукописный счётчик «4» и линию под «Vue 3 и TypeScript».

**Architecture:** `CopyEmail` меняет подпись на стопку из двух иконок. `useSound` вызывает `bind()` из `cuelume` один раз, ховер озвучивается data-атрибутами на существующих элементах, меню и копирование через `cue()`. Новый `CountUp` считает цифру по rAF, линия под стеком — класс `.tech-line` в `style.css`; первая строка рендерится через `I18nT` с двумя слотами.

**Tech Stack:** Vue 3.5 `<script setup>` + TypeScript, `cuelume` 0.2 (`bind`, `play`), vue-i18n 11 (`I18nT`), `@vueuse/core` (`usePreferredReducedMotion`), Tailwind 4 + `tw-animate-css`, vitest + jsdom + `@vue/test-utils`, pnpm.

Спек: `docs/superpowers/specs/2026-09-04-polish-d-design.md`.

## Global Constraints

- Пакетный менеджер `pnpm`: `pnpm test:run`, `pnpm type-check`, `pnpm lint`, `pnpm build`.
- Никаких `border`; переходы только по `opacity`, `scale`, `rotate`, `transform`, `color`, `background-color`; под reduced motion только `opacity`.
- Звук только при включённом переключателе: `cuelume` сам молчит после `setEnabled(false)`, а `cue()` дополнительно проверяет `soundEnabled`.
- Иконки только `~icons/material-symbols/<name>-rounded`.
- Комментарии на русском и только где нужно «почему». Сообщения коммитов на английском в стиле `git log`.
- Стейджить только файлы задачи; никогда `git add -A`. Коммит после каждой задачи.
- Tailwind 4: `scale-*`/`rotate-*` ставят нативные `scale`/`rotate`, переходы задавать на них (`[transition:opacity_220ms_var(--ease-standard),scale_220ms_var(--ease-standard),rotate_220ms_var(--ease-standard)]`).

- [ ] **Step 2: Компонент**

```vue
<script setup lang="ts">
import { onMounted, onScopeDispose, ref } from 'vue'
import { usePreferredReducedMotion } from '@vueuse/core'

const props = withDefaults(defineProps<{ to: number; duration?: number; delay?: number }>(), {
  duration: 550,
  delay: 300,
})

const reduced = usePreferredReducedMotion()
const shown = ref(0)
let frame = 0
let timer: ReturnType<typeof setTimeout> | undefined

function run() {
  const start = performance.now()
  const tick = (now: number) => {
    const p = Math.min(1, (now - start) / props.duration)
    shown.value = Math.round(props.to * (1 - Math.pow(1 - p, 3)))
    if (p < 1) frame = requestAnimationFrame(tick)
  }
  frame = requestAnimationFrame(tick)
}

onMounted(() => {
  if (reduced.value === 'reduce' || typeof requestAnimationFrame === 'undefined') {
    shown.value = props.to
    return
  }
  timer = setTimeout(run, props.delay)
})

onScopeDispose(() => {
  clearTimeout(timer)
  if (typeof cancelAnimationFrame !== 'undefined') cancelAnimationFrame(frame)
}, true)
</script>

<template>
  <span class="inline-block">
    <span
      class="t-hand inline-block min-w-[1.1ch] align-[-0.08em] text-[1.45em] tabular-nums text-primary"
      aria-hidden="true"
      >{{ shown }}</span
    >
    <span class="sr-only">{{ to }}</span>
  </span>
</template>
```

`align-[-0.08em]` — произвольное значение `vertical-align` в Tailwind 4; если не компилируется, использовать `[vertical-align:-0.08em]`.
