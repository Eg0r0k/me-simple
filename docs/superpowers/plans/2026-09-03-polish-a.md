# Полировка A: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Шапка отдельным компонентом со ссылкой «me» на главную, тело страницы в `Scrollable` с памятью прокрутки между страницами, плавная подгрузка кадров проектов, маркер «от руки» на слове «дня», ховер карточек на `/projects`.

**Architecture:** Пять независимых правок. `AppHeader.vue` забирает шапку из `App.vue`; `App.vue` становится колонкой «шапка + Scrollable». `useScrollMemory` хранит позиции по пути и подключается к роутеру. `ProjectShot` учится проявлять картинку. `Marker` рисует подложку и один раз «прорисовывает» её при попадании в кадр. Ховер карточек только классами.

**Tech Stack:** Vue 3.5 `<script setup>` + TypeScript, vue-router 5, vue-i18n 11 (`I18nT`), `@vueuse/core` (`useElementVisibility`), Tailwind 4 с токенами `src/style.css`, vitest + jsdom + `@vue/test-utils`, pnpm.

Спек: `docs/superpowers/specs/2026-09-03-polish-a-design.md`.

## Global Constraints

- Пакетный менеджер `pnpm`: `pnpm test:run`, `pnpm type-check`, `pnpm lint`, `pnpm dev`, `pnpm build`.
- Никаких `border`, `divide-*`; `transition` только по `background-color`, `color`, `opacity`, `transform`, `filter`; никакого `transition-all`.
- Ховер только под `hover: hover` (Tailwind 4 `hover:` уже так работает). Под `prefers-reduced-motion: reduce` анимации выключаются (`motion-reduce:` в Tailwind или `@media` в CSS).
- Каждый нажимаемый элемент получает `press-scale`.
- Иконки только `~icons/material-symbols/<name>-rounded`.
- Комментарии в коде и тестах на русском. Сообщения коммитов на английском в стиле `git log` («Add …», «Move …», «Fade …»).
- `noUncheckedIndexedAccess` включён.
- Коммит после каждой задачи, добавлять только названные в задаче файлы, никогда `git add -A`.
- Стили `Scrollable` лежат вне слоёв Tailwind, поэтому его `height: 100%` побеждает утилиты; размер задаётся флексом родителя (`flex-1 min-h-0`), а не классами высоты.

        { path: '/projects', component: Page },

`src/composables/useScrollMemory.ts`:

```ts
import { nextTick } from 'vue'
import type { Router } from 'vue-router'

export interface ScrollHost {
  get: () => number
  set: (position: number) => void
}

// Позиции прокрутки по полному пути: уход со страницы запоминает, приход восстанавливает.
export function createScrollMemory() {
  const positions = new Map<string, number>()

  return {
    save(path: string, position: number) {
      positions.set(path, position)
    },
    restore(path: string): number {
      return positions.get(path) ?? 0
    },
  }
}

// Окно не прокручивается, прокручивается контейнер Scrollable, поэтому
// scrollBehavior роутера бесполезен: позицию ведём сами через хост контейнера.
export function useScrollMemory(router: Router, host: () => ScrollHost | null) {
  const memory = createScrollMemory()

  router.beforeEach((_to, from) => {
    const current = host()
    if (current && from.matched.length > 0) {
      memory.save(from.fullPath, current.get())
    }
  })

  router.afterEach((to) => {
    // Новая страница появляется в DOM на следующем тике, до этого ставить позицию некуда.
    void nextTick(() => host()?.set(memory.restore(to.fullPath)))
  })

  return memory
}
```
