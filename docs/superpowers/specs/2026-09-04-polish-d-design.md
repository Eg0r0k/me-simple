# Полировка D: морф галочки, звуки на ховер и меню, акцент на первой строке

Дата: 2026-09-04. Три правки по обратной связи после части C. Ветка `feat/polish-d` от
`master`.

## 1. Копирование почты: морф иконки в галочку, без текста

- Подпись «Скопировано» убирается из видимой разметки. Для скринридеров остаётся
  визуально скрытый (`sr-only`) `aria-live="polite"` элемент с тем же текстом
  `contact.copied` на время подтверждения.
- Иконка справа от адреса становится стопкой из двух иконок в контейнере
  `relative size-[18px]`: `content_copy_rounded` и `check_rounded`, обе абсолютно
  позиционированы на весь контейнер. В покое видна копия (`opacity-100 scale-100
  rotate-0`, `--faint`), галочка скрыта (`opacity-0 scale-50 -rotate-45`). После
  успешного копирования на 1.4 с классы меняются местами: копия уходит
  (`opacity-0 scale-50 rotate-45`), галочка приходит (`opacity-100 scale-100 rotate-0`)
  цветом `--primary`. Переходы `opacity`, `scale`, `rotate` по 220 мс
  `--ease-standard`; под reduced motion только `opacity`.
- Кнопка получает `aria-pressed` не нужно; `aria-label` остаётся «адрес, Скопировать».
- Тест `CopyEmail.spec.ts` обновляется: после клика галочка получает класс
  `opacity-100`, копия `opacity-0`, через 1.4 с обратно; видимого текста «Скопировано»
  нет, `sr-only` элемент содержит его.

## 2. Звуки на ховер и на меню

Звуки уже есть: `cuelume` через `useSound` (`cue(name)`, включение хранится в
`localStorage`, по умолчанию выключено, кнопка в шапке). Палитра: `chime sparkle
droplet bloom whisper tick press release toggle success error page loading ready pulse
scan arrival`.

- Ховер: `cuelume` умеет делегированную привязку через data-атрибуты
  (`data-cuelume-hover="<name>"` срабатывает на `pointerenter`, `bind()` вешается
  один раз на документ и подхватывает элементы, добавленные позже). В `useSound.ts`
  при инициализации вызывается `bind()`; включённость звука по-прежнему через
  `setEnabled`, так что при выключенном звуке атрибуты молчат.
- Элементы с `data-cuelume-hover="whisper"`: строки проектов (`ListRow` внутри
  `ProjectList`), строки опыта, строки конкурсов, чипы стека, ссылка-заголовок
  «Проекты», кнопки шапки (язык, звук, тема) и бренд `me`, карточки на `/projects`,
  кнопка «Написать» и иконки Telegram/GitHub, кнопка почты. Слова с всплывающими
  карточками не озвучиваются: они не кнопки.
- Меню языка в шапке: `DropdownMenu` получает `@update:open`, на открытие
  `cue('bloom')`, на закрытие `cue('whisper')`.
- Копирование почты: после успешного копирования `cue('success')`.
- Клики, которые уже озвучены (`tick` на выбор языка и бренд, `toggle` на тему),
  не меняются. Ховер и клик по одному элементу дают два разных звука, это нормально.
- Тесты: `useSound` не тестируется (обёртка над библиотекой); проверка руками с
  включённым звуком.

## Ограничения дизайн-системы

Бордеров нет; переходы по `opacity`, `scale`, `rotate`, `stroke-dashoffset`; под reduced
motion только `opacity`; звук только при включённом переключателе; иконки Material
Symbols rounded.
