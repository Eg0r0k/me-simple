# Превью проекта у курсора

Дата: 2026-09-03. Секция «Проекты» на главной (`src/pages/HomePage.vue`).

## Цель

Список проектов в покое остаётся таким же тихим, как сейчас: название, подпись, год, стрелка.
Интерес появляется только от взаимодействия: при наведении на строку рядом с курсором
возникает карточка со скриншотом проекта, идёт за курсором с пружиной и меняет кадр
при переходе между строками. Секция «Опыт» в этой работе не меняется.

Дополнительно: в заголовке секции справа стоит количество проектов, а сам заголовок
ведёт на отдельную страницу `/projects`, где проекты показаны карточками со скриншотами.

  счётчик `t('projects.count', projects.length)` классом `t-label` (ключ с плюрализацией

## Поведение

### Десктоп: есть ховер и точный указатель

Условие: `@media (hover: hover) and (pointer: fine)`, читается через `useMediaQuery`
из `@vueuse/core`. Во всех остальных случаях (тач, стилус, гибриды без ховера) карточка
не рендерится вообще, список ведёт себя как сейчас.

- Карточка появляется, когда курсор входит в любую строку проекта, и исчезает, когда
  курсор покидает список проектов целиком. Между строками карточка не исчезает.
- Появление и исчезновение: `opacity` 0 → 1 и `scale` 0.96 → 1 за 180 мс, ease
  `--ease-standard`. Исчезновение те же значения в обратную сторону.
- Позиция: карточка центрируется по вертикали относительно курсора и стоит на 20px правее
  него. Если правый край карточки выходит за окно (с отступом 16px), карточка ставится
  на 20px левее курсора. Смена стороны происходит мгновенно, без анимации.
- Слежение: координаты курсора пишутся в два `useMotionValue`, за ними идут два
  `useSpring` со `stiffness: 400`, `damping: 40`, `mass: 1`. Карточка позиционируется
  через `position: fixed` и `transform: translate3d(x, y, 0)`.
- Наклон: угол берётся из горизонтальной скорости пружины x (`getVelocity()`),
  умножается на коэффициент 0.004 и ограничивается диапазоном −6…6 градусов.
  Сам угол тоже идёт через `useSpring`, чтобы не дёргался.
- Смена кадра: все кадры лежат в карточке стопкой в одном контейнере с
  `aspect-ratio: 16 / 9`. Активный кадр: `opacity: 1`, `translateY(0)`. Неактивные:
  `opacity: 0`, `translateY(8px)`. Переход 220 мс, `--ease-standard`. Кадры не
  размонтируются, поэтому картинки загружаются один раз.
- Карточка не перехватывает события: `pointer-events: none`.
- Фокус с клавиатуры карточку не показывает. Строка остаётся обычной ссылкой.

### Reduced motion

`MotionConfig reduced-motion="user"` в корне действует только на `:animate` у `motion.*`;
пружины `useSpring` его не читают. Поэтому при `prefers-reduced-motion: reduce` компонент
сам берёт позицию из сырых координат курсора, минуя пружины, наклон всегда 0, а появление
и смена кадра идут только по `opacity`, без `scale` и `translateY`. Проверяется через
`usePreferredReducedMotion` из `@vueuse/core`.

### Границы окна

Карточка не выходит за окно: по вертикали её верх зажат между 16px от верха и
16px от низа окна (по центру курсора, пока хватает места); слева при перекидывании
край не ближе 16px к левой границе. Ширина окна берётся без полосы прокрутки, чтобы
совпадать с системой координат `clientX`.

## Внешний вид карточки у курсора

- Ширина 280px, высота по `aspect-ratio: 16 / 9`.
- Радиус `--radius-3` (12px), тень `--shadow-2`. Это второй из двух разрешённых
  теней системы; бордеров нет.
- Внутри стопка `ProjectShot` по одному на проект (см. «Кадр проекта»).

## Кадр проекта: `ProjectShot`

Один компонент кадра для обоих мест, карточки у курсора и карточки на странице:

- Контейнер `aspect-ratio: 16 / 9`, `overflow: hidden`, радиус задаёт родитель.
- Скриншот: `object-fit: cover`, `object-position: top left`. Скриншоты не строго 16:9,
  обрезается нижний и правый край. Пока не загрузился, под ним фон `--sunk`.
- Плашка для проекта без скриншота (lyra-audio): фон soft-тона проекта (`--peri-soft`),
  текст `npm i lyra-audio` классом `t-code`, 14px, цвет ink-тона (`--peri-ink`), по центру.
  Тон берётся из `project.tone`, текст из поля `preview.command`.
- `alt` пустой: название проекта уже стоит рядом текстом.

## Картинки

Исходники лежат в `public/projects/<slug>/`. Для каждого создаётся WebP шириной 1120px
(2× от ширины карточки с запасом) рядом с исходником, той же базой имени. Конвертация
через `ffmpeg`, качество 82. Исходные PNG остаются в репозитории.

Соответствие языку:

| slug       | ru                                   | en                                   |
|------------|--------------------------------------|--------------------------------------|
| audiogram  | `/projects/audiogram/app-ru.webp`    | `/projects/audiogram/app-en.webp`    |
| typemore   | `/projects/typemore/app.webp`        | `/projects/typemore/app.webp`        |
| tuna       | `/projects/TunA/app-ru.webp`         | `/projects/TunA/app-en.webp`         |
| lyra-audio | плашка `npm i lyra-audio`            | плашка `npm i lyra-audio`            |

Если для текущего языка кадра нет, берётся `en`, если нет и его, первый доступный.
Текущий язык берётся из `useI18n().locale`.

## Данные

`src/data/projects.ts`, интерфейс `Project` получает поле:

```ts
preview:
  | { kind: 'image'; src: Partial<Record<'ru' | 'en', string>> }
  | { kind: 'command'; command: string }
```

Поле обязательное: у каждого проекта либо картинка, либо команда.

## Компоненты

### `src/components/project-list/ProjectList.vue`

Рендерит секцию проектов: заголовок остаётся в `HomePage.vue`, компонент отвечает за
список строк и карточку. Держит:

- `hoveredSlug: Ref<string | null>`, ставится на `pointerenter` строки, сбрасывается на
  `pointerleave` контейнера списка.
- `pointerX`, `pointerY` как `useMotionValue`, обновляются на `pointermove` контейнера.
- `canHover` из `useMediaQuery`.
- `locale` из `useI18n()`, передаётся в карточку пропсом.

Строки рендерятся через существующий `ListRow` без изменений. Карточка рендерится
только при `canHover`.

### `src/components/project-list/ProjectPreview.vue`

Пропсы: `projects: Project[]`, `activeSlug: string | null`, `pointerX`, `pointerY`
(motion values), `locale`. Внутри: пружины, вычисление стороны, наклон, стопка
`ProjectShot`. Не знает про i18n напрямую: получает `locale` пропсом, чтобы оставаться чистым.

### `src/components/project-list/ProjectShot.vue`

Пропсы: `project: Project`, `locale`. Рендерит картинку или плашку с командой по
`resolvePreviewSrc`. Используется в карточке у курсора и на странице `/projects`.

### `src/pages/ProjectsPage.vue`

Страница с сеткой карточек, описана в разделе «Страница `/projects`». Карточка живёт
прямо в странице, отдельного компонента для неё нет: она используется в одном месте.

### `src/components/project-list/preview.ts`

Чистые функции без Vue:

- `resolvePreviewSrc(preview, locale): string | null` по правилу фолбэка выше.
- `clampTilt(velocity: number): number` — коэффициент 0.004, диапазон −6…6.
- `placeCard(pointerX, cardWidth, viewportWidth): 'right' | 'left'` — отступ 16px,
  сдвиг 20px.

### `HomePage.vue`

Секция проектов: заголовок становится строкой-ссылкой со счётчиком (см. «Заголовок
секции на главной»), цикл `ListRow` заменяется на `<ProjectList :projects="projects" />`.
Остальное не меняется.

### Роутер

`route-names.ts`, `route-locations.ts`, `routes/pages.ts` получают маршрут `projects`.

## Тесты

Vitest, `src/components/project-list/preview.spec.ts`:

- `resolvePreviewSrc`: ru есть → ru; ru нет, en есть → en; только один язык → он;
  команда → `null`.
- `clampTilt`: 0 → 0; 500 → 2; 5000 → 6; −5000 → −6.
- `placeCard`: карточка помещается справа → `right`; не помещается → `left`.

Само движение и кроссфейд проверяются руками в dev-сервере на десктопе, в эмуляции
тача в DevTools и с включённым reduced motion.

## Ограничения из дизайн-системы, которые соблюдаются

- Бордеров нет, разделение тоном и тенью `--shadow-2`.
- Анимация только по `opacity` и `transform`.
- Моно только для настоящей команды в терминале.
- Ховер только под `hover: hover`.
- Ничего не привязано к скроллу, бесконечных циклов нет.
